# Chrome已拦截弹窗列表

仅打开已观察的浏览器外壳列表，不选择链接，不修改弹窗设置。

```sh
python3 skills/douyin-laike-operator/scripts/chrome-popup-navigation.py --mode open-list --out /绝对路径/唯一popup-intent.json --expected-pid 实际Chrome主进程PID --bridge-focus /绝对路径/focus.json
```

focus.json保留实际桥activate和随后tabs原始响应，封装为source=`local-dom-bridge`、observed_at、expected_pid、groupid、tabId、windowId、activation（原始result）、tabs（枚举数组）。activate字段为tabId/windowId/url/title/active/windowFocused/observedAt/safety_version，版本须dom-only-20261021-6。两次证据须60秒内、同一实际tab/window/group；枚举窗口focused且标签active。不能手填true代替实际桥响应。

程序验证Chrome主进程、唯一AXMain标准窗口及标题绑定，排除全部AXWebArea，唯一enabled AXButton「已拦截弹出式窗口」才允许AXPress。意图先落盘，按一次后保存完整外壳树。重复使用同一out只读返回已有状态，不再调用AX。unknown不可换文件绕过重发，应保留原记录供监理复查。当前没有记录页链接模式，须取得真实菜单树后再增加精确白名单。

11项纯mock测试覆盖写前意图、未知不重放、窗口/按钮唯一性、group与激活证明，以及真实遍历函数不读WebArea属性/子树。没有据此声称真机通过。

已观察的记录页链接入口：`--mode open-record-link --list-intent /原open-list完成.json --list-intent-sha256 原文件实际SHA256`，其余PID/focus/out参数相同。仅原已完成列表链、相同源tab/window/group、独立原生窗口「已拦截弹出式窗口：」内唯一逐字同标题AXLink可按一次。Chrome未提供完整AXURL时不猜URL，按其已观察截断标签定位；若提供公开URL则先核origin/path/group。点击后只枚举真实新增tab，核实际life.douyin.com的export_records/20101路径与同group才认定完成。菜单若已关闭就停止，不重开原列表，不碰允许/完成/设置。unknown保留原意图，不换文件重放。
