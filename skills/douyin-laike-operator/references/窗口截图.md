# 整窗证据接口（尚未真机验收）

```sh
python3 skills/douyin-laike-operator/scripts/window-evidence.py --build-helper
python3 skills/douyin-laike-operator/scripts/window-evidence.py --pid 实际Chrome主进程PID --window-id 实际CGWindowID --dom-evidence /绝对路径/实际DOM取证.json --out /绝对路径/新截图.png
```

先只编译本地Swift助手，再取得新鲜DOM证据。截图使用公共ScreenCaptureKit/SCScreenshotManager的desktopIndependentWindow过滤；Python与助手均先核对屏幕录制权限，未授权不采集、不请求授权。只捕获指定Chrome整窗，不点击、不裁剪、不读像素定位、不激活窗口、不启动Chrome。CGWindowID与Chrome扩展windowId不是同一编号，必须先核验，不能混用。已移除旧CGWindowListCreateImage调用。

DOM取证JSON：source=`local-dom-bridge`、observed_at（带时区，60秒内）、tab_id、groupid、date_range（start/end均含）、tabs（桥实际枚举的窗口数组）、tree（桥实际完整语义树）、bindings。bindings为date及headers数组，每项 `{selector:实际叶节点selector,text:实际完整文本}`。date须对应筛选日期；headers须真实表头。focused窗口须唯一，active tab须唯一；其title与前台CGWindow唯一匹配，完整URL的groupid匹配，tree路径匹配。不能给JSON填true替代实际枚举/DOM。

输出PNG与同名JSON，含PNG哈希、窗口元数据、DOM文件哈希、tab/group/date/header绑定。`source=macos-public-screencapturekit`，不自动认定覆盖：`coverage_verified=false`、`content_review_required=true`、`live_accepted=false`。执行岗须捕获后再次核验tab/group/date，并查看实际图是否覆盖目标评价/通知书及筛选表头，再以真实ID登记。不能用表格渲染图或参考图片冒充页面证据。当前仅完成本机编译和mock测试，实际截图待权限后验收。
