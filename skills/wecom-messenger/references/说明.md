# 安装、权限与结果

将整个wecom-messenger目录复制至目标工作区skills下，或个人 `~/.codex/skills/` 下。需要macOS、Python 3.9+、已登录的企业微信，当前适配客户端5.0.12的实际UI树；不依赖第三方Python包。

1. 运行 `python3 scripts/messenger.py doctor`。
2. 若返回accessibility-permission-required，打开系统设置→隐私与安全性→辅助功能，授权实际运行宿主（如Codex或Terminal），然后重跑doctor。本次宿主已有权限，无需新增。
3. 使用SKILL中的prepare/run。`status --job ...`只读状态，`step --job ...`只推进代码决定的一步。工具输出是JSON，适合外部程序调用。

模块职责：native.py绑定公开AX/CoreGraphics API；ui.py固定语义选择器；messenger.py固定状态机、名单、锁与回执；files.py校验富文本附件URL及发送确认，pasteboard.py临时写入文件URL并恢复剪贴板。文档不维护另一份点击SOP。

默认状态保存在项目runtime/wecom-messenger下；可通过prepare的--directory指定目录。成功后相同key不会再发；同key改目标/内容拒绝。所有进程共享目录锁；只能有一个操作者使用企业微信。不要在运行中手动切换聊天或输入，程序检测到变化会停。

文件发送通过公开剪贴板API暂存文件URL；旧格式只在内存保留，不记录或落盘，发送后恢复。若检测到其他应用已改剪贴板，则保留新内容而不覆盖。

出现unknown时禁止删除状态或换key重发。先检查该目标的实际聊天记录和待发送内容；没有证据不能标成功。程序不会清理别人的草稿、撤回消息或自动处理验证码。

测试：`python3 -m unittest discover -s tests -q`。真实测试凭证保存在工作区 `work/wecom-test-20261020/`，不包含在代码交付包里。

实测范围见[验收](验收.md)。
