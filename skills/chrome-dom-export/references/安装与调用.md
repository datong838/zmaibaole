# 安装与调用

## 目录结构

```text
chrome-dom-export/
├── SKILL.md
├── .gitignore
├── extension/
│   ├── manifest.json
│   ├── policy.js              离线审核的站点操作白名单
│   ├── worker.js              扩展后台；只连接 127.0.0.1
│   ├── content.js             ISOLATED world 的 DOM 读取/语义操作
│   ├── control.html
│   └── control.js             扩展控制页；可选快速轮询
├── scripts/
│   ├── install.py             复制到 Codex skills；拒绝覆盖
│   └── bridge.py              HTTP 服务＋CLI＋下载等待
├── tests/
│   ├── test_bridge.py
│   ├── content.test.cjs
│   └── worker.test.cjs
└── references/安装与调用.md
```

初始化后额外生成 `.local/config.json`（两个本机密钥和绑定扩展 ID）、`extension/config.js`（仅扩展桥接密钥），权限 0600。不要上传、打包或分享这些生成文件。密钥不是用户网站认证信息，不读取网站 cookie。初始交付压缩包不含密钥。

## 需要什么授权

| 项目 | 范围与理由 |
|---|---|
| macOS 辅助功能 | DOM读/导出不需要；可选AX截图授权助手需要已有辅助功能权限，只点击现有Chrome扩展action |
| macOS 屏幕录制 | DOM读/导出不使用。标签截图走Chrome公开captureVisibleTab；未调用系统截图API，实际Chrome授权仍待验收 |
| Chrome `tabs` | 枚举窗口/标签的 ID、标题、URL（会包含其他标签的元数据；其他网站正文不会读取） |
| Chrome `activeTab` | 仅截图提案新增；真实扩展action调用获得临时目标页访问，不以程序activate或控制页tick假称授权；不加all_urls |
| Chrome `scripting` | 在已打开的抖音来客标签注入打包的 content script，不刷新页面 |
| Chrome `downloads` | 查询 Chrome 下载状态/落盘路径；实现按来源、时间、文件类型过滤 |
| Chrome `alarms` | 后台约每 30 秒轮询一次，无常驻调试会话 |
| Chrome `storage` | 扩展自身storage.session中的下载票据、刷新/截图意图与action调用凭证；不存截图base64、不读页面存储 |
| 网站权限 | 仅 `https://life.douyin.com/*` 和 `http://127.0.0.1/*`；manifest 的回环匹配覆盖端口，代码与 CSP 只访问 17341 |
| 可能出现的本地网络许可 | 仅在 Chrome/系统实际要求时允许此扩展访问本机回环；不需要局域网其他设备或公网代理 |

**不申请 debugger、cookies、webRequest、nativeMessaging 或全站访问权限。** 扩展页面不对网站暴露密钥和控制接口，无 `externally_connectable`、无 `web_accessible_resources`。HTTP 服务区分 CLI 与扩展密钥，扩展 Origin 必须等于本地绑定 ID；拒绝网站 Origin、错误 Host 和 CORS 预检。

Chrome「扩展程序 → 开发者模式」只用于加载解压扩展，**不是打开 DevTools，也不是启用调试端口**。整个安装不要打开“检查视图/Service worker 检查”、开发者工具或浏览器调试服务。扩展内脚本使用的是 Chrome 官方 content script/scripting API。

## 一步一命令安装（保留现有 Chrome 和登录态）

要求：Python 3.9+、Chrome 120+。无需 pip/npm 安装，不启动任何浏览器驱动。如果接收方机器禁止加载解压扩展，停止并请管理员按组织政策分发；不能绕过限制。

1. 在当前交付目录执行复制安装（目标已存在会拒绝覆盖）：

```sh
python3 scripts/install.py
```

也可指定目标：`python3 scripts/install.py --dest /你的绝对路径/chrome-dom-export`。后续命令据此替换。默认安装后设置目录变量（每个新终端执行一次）：

```sh
export DOM_SKILL="$HOME/.codex/skills/chrome-dom-export"
```

2. 创建本机密钥与扩展配置；不显示密钥：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" init
```

3. 在**已经打开的 Chrome** 地址栏手工输入 `chrome://extensions`；打开“开发者模式”，点击“加载已解压的扩展程序”，选择下一命令显示的目录。该授权动作不能用命令行静默代办。

```sh
printf '%s\n' "$DOM_SKILL/extension"
```

4. 在扩展卡片复制 32 字符 ID（不要点击“检查视图”）。命令里的示例 ID 必须替换成真实 ID：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" bind abcdefghijklmnopabcdefghijklmnop
```

5. 启动回环服务，保持这个终端打开。若端口被占用，停止并查明；不要改成 `0.0.0.0`。服务永远不会启动 Chrome：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" serve
```

6. 点 Chrome 扩展图标中的 **Local DOM Export Bridge (No Debugger)**，会打开其控制页。控制页显示 `connected: true` 后可操作；保持页面打开可约每秒取任务，关闭后约每 30 秒取任务。首次页面显示尚未绑定/未启动服务是正常状态。绑定 ID 后如服务已在运行，只重启本地 Python 服务，不重启 Chrome。

7. 新开终端设置 `DOM_SKILL` 后验证服务：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" status
```

8. 枚举窗口和标签：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" tabs
```

9. 下面用上一步实际的抖音来客 `tabId` 替换示例 `123`：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"ping","tabId":123}'
```

10. 读取 UI 树/DOM 语义结构：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"tree","tabId":123}'
```

不需要重新登录；本包只复用已登录页面。如果显示登录页/风控/验证码则停止，用户自行处理。

## 外部程序接口

### CLI（推荐）

所有命令输出 JSON；失败返回非零退出码。`request` 接受一个 JSON 参数。默认等待扩展最多 90 秒，`--timeout` 可设置 1—95 秒。超时的点击可能已执行，禁止盲重试，先读树确认。只允许一个调用方串行操作。

按精确文本查找：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"find","tabId":123,"locator":{"by":"text","value":"导出评价"}}'
```

按角色和可访问名称查找：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"find","tabId":123,"locator":{"by":"role","value":"button","name":"导出"}}'
```

按当前树返回的 CSS 路径查找/限定子树（示例 `main` 须在当前树真实存在）：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"tree","tabId":123,"locator":{"by":"selector","value":"main"}}'
```

点击唯一且已审核的导出入口（先确认当前页面与筛选，再执行）：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"click","tabId":123,"kind":"export","locator":{"by":"text","value":"导出评价"}}'
```

点击后重新执行 `tree`，核对弹窗，再按当前 DOM 选择日期。初始日历支持 `.byted-date-col.byted-date-date` 内 1—31 的数字；同一天在两个月份出现时必须用树中的父子结构限定选择器，不能盲选第一个。

只填经过审核的搜索框（日期 readonly 时使用日历控件，不强改 DOM）：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"filter","tabId":123,"locator":{"by":"selector","value":"input[placeholder=搜索商户]"},"value":"烟台一成"}'
```

下载链路：先打开评价导出记录、等平台显示生成成功，并找到唯一正确记录的下载元素。**在真正点击下载之前**取票据：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"download-begin","tabId":123}'
```

记录页状态未更新时可用窄刷新（1.0.10 / dom-only-20261021-4），示例ID、groupid、工单key须换为实际值。只刷新已存在的`/p/fulfillsettle/export_records/20101`；15秒内须观察loading→complete并核对完整URL/ID。未知不改key重发；同key已成功只返回缓存结果。刷新不创建新导出任务。

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"reload-records","tabId":123,"groupid":"1767942028615694","reloadKey":"current-work-order-record-refresh-1"}'
```

记录输出 `result.ticket`，然后按当前树的唯一文本/角色/选择器点击该记录的“下载”：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" request '{"op":"click","tabId":123,"kind":"download","locator":{"by":"text","value":"下载"}}'
```

有多个“下载”时，此命令会拒绝；必须改为真实目标行里返回的 CSS 路径。

```sh
python3 "$DOM_SKILL/scripts/bridge.py" wait-download 替换为真实票据 --timeout 180
```

如同时有多个下载，指定精确文件名：

```sh
python3 "$DOM_SKILL/scripts/bridge.py" wait-download 替换为真实票据 --filename '门店评价.xlsx' --timeout 180
```

成功输出示意（不是本次真实文件）：

```json
{"ok":true,"result":{"state":"complete","path":"/Users/你的用户名/Downloads/门店评价.xlsx","exists":true,"localFileVerified":true,"localSize":12345}}
```

文件路径来自 Chrome `downloads` API，不猜下载目录、不根据文件名搜索全盘。候选只含票据之后的新下载、允许的表格/压缩扩展名，且 URL/finalUrl/referrer 至少一个属于抖音来客（支持其 blob URL）。未带站点来源的独立 CDN 下载会拒绝，需人工核对来源后离线修订策略。不能精确证明某下载属于某标签，因此运行期间不要另开同源下载；多候选立即拒绝，不取“最新一个”。票据 10 分钟失效、浏览器重启后失效，不用于重复点击下载。

### HTTP

服务固定 `http://127.0.0.1:17341`。所有端点仅 POST，JSON 内容。每个客户端从本机 `.local/config.json` 读取 `cliToken`，通过 `Authorization: Bearer ...` 传输；不要在命令参数、日志或网页里输出密钥。请求格式：

```json
{"command":{"op":"tree","tabId":123},"timeout":90}
```

- `POST /v1/status`：请求体 `{}`，读取心跳。
- `POST /v1/request`：执行上述白名单命令，返回 `{ok,result,error}`。
- `/bridge/poll`、`/bridge/result` 是扩展内部协议，只接受独立 `bridgeToken` 和绑定扩展 Origin。外部 agent 不调用。

外部 Python 无第三方依赖调用示例（完整可运行，修改目录/tabId）：

```python
import json
from pathlib import Path
from urllib.request import Request, build_opener, ProxyHandler

root = Path.home() / '.codex/skills/chrome-dom-export'
config = json.loads((root / '.local/config.json').read_text())
payload = {'command': {'op': 'tree', 'tabId': 123}, 'timeout': 90}
request = Request(config['base'] + '/v1/request',
                  data=json.dumps(payload).encode(),
                  headers={'Authorization': 'Bearer ' + config['cliToken'],
                           'Content-Type': 'application/json'}, method='POST')
assert config['base'] == 'http://127.0.0.1:17341'
with build_opener(ProxyHandler({})).open(request, timeout=100) as response:
    result = json.load(response)
print(json.dumps(result, ensure_ascii=False, indent=2))
```

无远程调用、无任意命令执行、无 JS evaluate、无网络代理、无 cookie/存储读取、无像素坐标参数、无任意 URL 导航或上传能力。

## 升级白名单和撤销

先 `find`/`tree` 只读观察真实控件；人工确认其业务语义后修改 `extension/policy.js`。如果某按钮可能回复/投诉/发布，不加入。CSS 选择器只是定位方式，不能绕过白名单和拒绝词。保存后在 `chrome://extensions` 点此扩展“重新加载”，再执行 `tree`（脚本自动注入现有页面，无须刷新目标站点）；重新加载后不要复用旧下载票据。

撤销：在 Python 服务终端按 Ctrl+C；在 Chrome 扩展管理页移除此扩展。可手动删除安装目录；不涉及 Chrome 用户 profile。没有常驻进程注册，没有自启动服务或权限提升。

## 验收和已知限制

离线命令：

```sh
python3 -m unittest discover -s "$DOM_SKILL/tests" -p 'test_*.py' -v
```

```sh
node "$DOM_SKILL/tests/content.test.cjs"
```

```sh
node "$DOM_SKILL/tests/worker.test.cjs"
```

Node 仅用于离线测试，不是运行依赖。交付者已完成 Python HTTP 集成测试与 mock DOM/worker 测试；这些不能证明真实 Chrome 中下载/页面兼容。真实扩展尚未安装、授权和站点验收。

安装后按顺序验收：`status` 有心跳 → `tabs` 显示真实标签 → `tree` 显示已登录业务页面 → `find` 精确找到已知导航 → 点击后树发生预期变化 → 取下载票据 → 点击已生成记录的下载 → `wait-download` 输出真实绝对路径且 `localFileVerified: true`。不通过时只记录失败，不降级到调试/坐标。不以历史截图或模拟文件冒充本次验收。

DOM 结构树只包含当前可见元素，不覆盖离屏虚拟列表、iframe 或关闭 shadow DOM；名称/角色采用显式 ARIA、HTML 标签、label、文本/placeholder 推导，未实现完整浏览器 accessible-name 算法。不会接管系统原生保存对话框；若 Chrome 打开“另存为”，等待用户确认。

参考官方文档：[Content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[downloads](https://developer.chrome.com/docs/extensions/reference/api/downloads)、[alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms)。这里的实现不调用上述之外的任何调试协议。
